# Style Board Generation Prompt

Tool path: Codex built-in image generation (`gpt-image-2`)  
Use case: `stylized-concept`

## Final prompt

Create one cohesive polished pixel-art visual style board for an original 16:9 browser rescue puzzle game. Show three clearly distinct cute rescue robots, a bright small-town rescue environment, dark navy game UI panels, and small key VFX samples for fire, water, repair sparks, and rescue hearts.

`AQUA` is cyan and blue with a round water-tank backpack and a short wide water-cannon arm. `FIX` is yellow and orange with a square safety helmet, oversized wrench arm, and tool bag. `BUDDY` is coral red and pink with a heart-shaped chest light, long rescue arms, and a small beacon. Show each robot as a front hero pose plus a small side/back silhouette and one role-action pose.

Include a compact orthographic town vignette with a bakery, rooftop cat house, wooden bridge over a river, power station, rescue headquarters, paths, grass, trees, and plaza. Include chunky rounded dark navy UI panels with cream highlights, cyan/yellow/coral accents, button frames, and timer/health/incident icon shapes. Add small isolated VFX examples.

Use original modern hand-placed pixel art, consistent source-pixel scale, limited cohesive palette, crisp hard edges, one-source-pixel dark navy outlines, top-left lighting, and readable silhouettes at tiny scale. Organize the art-direction board with generous separation between robot lineup, town vignette, UI kit, palette swatches, and VFX. Use warm cheerful daylight that feels urgent but friendly.

Palette: `#172033`, `#24314D`, `#34486B`, `#FFF4D6`, `#39BFF2`, `#1975C5`, `#FFD34E`, `#D98C2B`, `#FF6577`, `#C93F5B`, `#70D98B`, `#F58B3D`, `#F04455`, `#80C96B`, `#3F8F5B`, `#54C7EC`, `#287DB2`, `#D7AA68`, `#9B603F`, `#A9C4D4`, `#667085`.

The robots must remain distinguishable in black silhouette by tank, helmet/tool, and long rescue arms. UI must be darker than the world. Fire must use orange-yellow with a pale hot core so it cannot be confused with BUDDY. No text or labels, logo, watermark, copyrighted character resemblance, gradients, fake letters, blur, 3D rendering, photorealism, gore, horror, thin lines, microtexture, cropping, or inconsistent pixel sizes.

## Post-processing

The selected output was resized with nearest-neighbor sampling to exactly `1920×1080` and saved as `pp_style_board.png`. It is used as an art-direction reference only; exact P0 assets are recreated through the deterministic pixel generator.
