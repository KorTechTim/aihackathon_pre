# PIXEL PANIC 맵 변형 생성 기록

기준 이미지는 `pp_stage_01_preview.webp`입니다. 아래 네 변형은 같은 40×17 시설 토폴로지와 카메라 구도, 16비트 픽셀 아트 스타일을 유지하도록 이미지 생성 도구로 제작한 뒤 중앙 크롭과 WebP 변환만 수행했습니다. 충돌·사고·NPC 좌표는 `pp_stage_01.json`, `pp_stage_01_collision.json`, `pp_stage_01_spawn_points.json`을 공통으로 사용합니다.

- 폭우: 짙은 비구름, 빗줄기, 젖은 돌길의 반사, 불어난 청록색 하천을 추가하되 건물과 다리 위치는 유지.
- 야간: 깊은 남색 밤하늘, 창문과 가로등의 따뜻한 불빛, 달빛과 강물 반사를 추가하되 시설 실루엣과 동선은 유지.
- 가을: 주황·금빛 단풍, 낙엽, 따뜻한 오후광을 추가하되 길·강·다리·시설 좌표는 유지.
- 설원: 눈 덮인 지붕과 나무, 얼어붙은 가장자리, 차가운 겨울광을 추가하되 길은 식별 가능하게 하고 시설 좌표는 유지.

공통 제약: 텍스트·UI·캐릭터·사고 아이콘을 넣지 않고, 상단 HUD 64px을 제외한 게임 배경으로 사용하며, 최종 출력은 각 1280×544 불투명 WebP입니다.

## 고유 레이아웃 4종

아래 맵은 내장 `image_gen` 도구에 원본 맵을 스타일 참조로 전달해 새로 생성했습니다. 원본과 색감·픽셀 밀도·아이소메트릭 시점만 맞추고, 시설 토폴로지는 새로 설계했습니다. 생성본을 중앙 크롭한 뒤 1280×544 불투명 WebP로 정규화했습니다.

- `pp_stage_06_harbor.webp`: 청록색 L자 항구가 좌하단을 감싸고 하단 중앙 석조 부두·아치교로 이어지는 해안 마을. 구조 본부는 좌상단, 발전소는 우상단, 빵집은 우하단, 주택과 시장은 중앙에 배치. 텍스트·UI·캐릭터 없음.
- `pp_stage_07_highland.webp`: 좌상단에서 하단 중앙으로 흐르는 계곡과 목교, 층층이 올라가는 산악 테라스 마을. 구조 본부는 상단 중앙 고지대, 발전소는 좌하단, 빵집과 주택은 우측, 하단 중앙은 하트 전망 정원. 텍스트·UI·캐릭터 없음.
- `pp_stage_08_canals.webp`: 중앙 정원을 감싸는 수평 고리형 운하와 두 개의 다리를 둔 정원도시. 발전소는 좌상단, 빵집은 우상단, 구조 본부는 하단 중앙, 주택은 하단 양쪽에 배치. 텍스트·UI·캐릭터 없음.
- `pp_stage_09_railway.webp`: 좌하단에서 우상단으로 달리는 대각선 철도와 중앙역, 하단 1/3을 가로지르는 강과 우측 철교가 있는 산업 마을. 구조 본부는 좌상단, 상점·주택은 상단 중앙, 발전소는 우하단, 하트 공원은 좌하단에 배치. 텍스트·UI·캐릭터·열차 없음.
