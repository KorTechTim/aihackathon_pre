# PIXEL PANIC 게임 설계

## 핵심 루프

한 판은 210초이며 모든 입력은 클릭 또는 터치입니다.

```text
사고 선택 → 로봇 선택 → 행동 선택 → 이동/작업 → 확산 또는 해결 → 콤보/대화 → 결과
```

게임 데이터와 판정은 `lib/rescue-engine.ts`에 있고 React와 Phaser는 이 결과를 표시합니다. 기본 시드 `20260807`을 사용하므로 같은 시간과 행동 순서는 같은 결과를 냅니다.

지도 빈 공간은 마우스나 터치로 좌우 드래그할 수 있습니다. 지도와 사고 핀은 함께 이동하고 HUD는 고정되며, 좌우 방향키도 같은 탐색 범위에서 동작합니다.

## 웨이브와 사고

| 웨이브 | 시작 | 사고 |
|---|---:|---|
| 화재 기초 | 0초 | 전기 합선, 빵집 화재, 가스 폭발 위험 |
| 폭우와 침수 | 65초 | 발전소 침수, 하천 범람, 다리 파손, 서쪽 주민 고립 |
| 복합 재난 | 135초 | 민가 확산 화재, 옥상 고양이, 동쪽 주민 고립 |

경고 상태의 사고도 선행 조치할 수 있습니다. 활성 사고의 확산 타이머가 0이 되면 위험도가 오르고 마을 보존율과 점수가 감소하며 연결 사고가 활성화됩니다. 해결한 사고는 더 확산하지 않습니다.

## 로봇과 행동

- AQUA: 화재 진압, 수위 감소, 주변 방화 처리
- FIX: 전력·가스 차단, 발전 시설 복구, 임시 다리, 장애물 제거
- BUDDY: 주민 대피·구조, 수리 부품 운반, 고양이 구조

각 로봇은 한 번에 한 작업만 수행합니다. 부품을 먼저 운반하면 발전 시설 복구 시간이 30% 줄어듭니다. 대화가 열려 있는 동안 사고 시간은 70% 속도로 흐릅니다.

## 사운드

`lib/audio-engine.ts`가 외부 음원 파일 없이 오리지널 32스텝 8비트 BGM을 실시간 합성합니다. 첫 타이틀 화면은 밝고 차분한 96 BPM 구조대 테마를, 실제 작전은 긴장감 있는 112 BPM 테마를 사용합니다. 타이틀 진입 시 자동 재생을 시도하며 브라우저 정책이 막으면 첫 클릭·터치·키 입력에 즉시 재생하고, 작전 시작 시 임무 테마로 자연스럽게 전환합니다. 선택, 대화, 출동, 사고 해결, 콤보, 웨이브 전환, 성공과 실패에는 각각 다른 효과음이 연결되며 음소거와 일시정지 상태를 따릅니다.

## 연쇄 사고

```text
전기 합선 → 빵집 화재 → 가스 위험 → 민가 화재
발전소 침수 → 하천 범람 → 다리 파손 → 주민 고립
```

선행 사고를 확산 전에 해결하면 해당 확산은 일어나지 않습니다. 이미 경고가 표시된 후속 사고는 직접 선택해 미리 처리할 수 있습니다.

## 콤보

| ID | 순서 |
|---|---|
| `power_cut_fire` | FIX 전력 차단 → AQUA 화재 진압 |
| `evacuate_gas_fire` | BUDDY 주민 대피 → FIX 가스 차단 → AQUA 진압 |
| `parts_repair` | BUDDY 부품 운반 → FIX 설비 복구 |
| `drain_bridge_rescue` | AQUA 수위 감소 → FIX 임시 다리 → BUDDY 구조 |
| `clear_firebreak` | FIX 장애물 제거 → AQUA 주변 방화 처리 |

정의된 순서와 제한 시간 안의 완료 행동만 콤보가 됩니다. 순서 사이에 다른 안전 행동이 있어도 상대 순서가 유지되면 인정하지만, 역순은 인정하지 않습니다.

## 점수와 결과

- 사고 해결 +100, 행동 완료 +20
- 주민 구조, 고양이 구조, 콤보, 남은 시간 보너스
- 사고 확산 -100 및 마을 보존율 감소
- S: 보존율 90% 이상, 주민 9명 구조, 콤보 3개 이상
- A: 보존율 75% 이상 / B: 55% 이상 / C: 0~54%

시간 종료 또는 보존율 0이면 실패 결과로 전환됩니다. 결과 화면에서 해결 사고, 구조 주민, 보존율, 콤보, 최대 콤보, 남은 시간과 등급을 확인하고 다시 시작할 수 있습니다.
