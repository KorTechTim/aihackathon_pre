# AI 활용 기록

## 개발 과정

GPT-5.6 Codex를 다음 작업에 활용했습니다.

- 결정론 사고 상태 머신과 콤보 판정 설계
- Next.js/React/Phaser UI 통합과 클릭 조작 구현
- Fastify 요청 검증, timeout, 폴백과 테스트 작성
- 픽셀 그래픽 제작 보조, 시각 QA, README와 배포 문서 작성

최종 코드는 자동 테스트와 브라우저 플레이로 검증하며, 저장소의 코드와 데이터가 게임 규칙의 기준입니다.

## 게임 실행 중 AI

- 모델 기본값: `gpt-5.6-luna`
- API: OpenAI Responses API
- 목적: 클릭한 지도 NPC와 구조 로봇의 현재 상황에 맞는 한국어 대사 1~3문장 생성
- 출력: `{ "dialogue": "..." }` 한 필드, 최대 160자
- timeout: 최대 5초, 재시도 없음
- 저장: API 요청의 `store: false`

지도 NPC는 이름·직업·성격 특성, 웨이브, 남은 시간, 마을 보존율, 해결 사고 수와 현재 선택 사고를 프롬프트로 전달합니다. 시스템 지시는 캐릭터 말투를 유지한 1~2문장, 새 사고·임무·보상·규칙·선택지 생성 금지, 마크다운 없이 120자 이하를 요구합니다. 기존 선택형 이벤트는 화자, 성격, 상황 ID, 사실과 미리 정의된 선택지 ID를 전달하며 최대 160자로 제한합니다.

## AI가 하지 않는 일

LLM은 다음을 결정하지 않습니다.

- 사고 상태와 확산 타이머
- 로봇 이동·작업 시간
- 선택지 생성과 선택 결과
- 콤보, 점수, 등급, 성공과 실패

이 항목은 모두 `lib/rescue-engine.ts`의 결정론 규칙이 계산합니다. NPC마다 성격에 맞는 정적 대사를 별도로 준비했으며, OCI/OpenAI가 없거나 timeout·오류·잘못된 응답이 발생하면 같은 말풍선에서 즉시 폴백합니다. 선택형 이벤트도 정적 문구와 선택지가 먼저 존재하므로 게임은 끝까지 진행됩니다.

## 키와 개인정보

브라우저는 OpenAI를 직접 호출하지 않습니다. OpenAI 키는 OCI VM의 저장소 밖 환경파일에만 두고, Vercel과 OCI 사이에는 별도 32바이트 이상 공유 토큰을 사용합니다. 원문 대사 요청, 키와 토큰은 감사 로그에 남기지 않습니다.

## 그래픽과 오픈소스

캐릭터, 맵, UI, 효과, 로고는 프로젝트용 오리지널 에셋이며 생성 과정에서 AI 이미지 제작 보조를 사용했습니다. BGM과 효과음도 프로젝트용 오리지널 음형을 코드로 작성해 Web Audio로 합성하므로 외부 음원이나 샘플을 포함하지 않습니다. 프레임워크와 라이브러리는 `package.json`, `backend/package.json`과 lockfile에 버전이 고정돼 있고 각 배포 패키지의 오픈소스 라이선스를 따릅니다.
