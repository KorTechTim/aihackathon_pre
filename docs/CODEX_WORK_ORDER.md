# Codex 통합 작업 범위

이 문서는 2026-08-06 추가 작업 지시서의 구현 기준과 저장소 반영 결과를 요약합니다.

## P0 반영 범위

- 클릭·터치 전용 입력, 자연어 입력 제거
- 210초, 3웨이브, 사고 10개
- 화재·침수 연쇄 사고 2개
- AQUA/FIX/BUDDY 행동과 중복 임무 방지
- 행동 순서 기반 콤보 5개
- 선택 결과가 미리 정의된 대화 4개
- GPT-5.6 대사 전용 API와 로컬 폴백
- 점수, 보존율, S/A/B/C 결과, 다시 하기
- 1280×720 기준 반응형 스테이지와 모바일 세로 회전 안내
- 게임 엔진, Vercel 프록시, OCI API, 브라우저 완주 테스트

## 구현 경계

결정론 게임 규칙은 `lib/rescue-engine.ts`, 클릭 UI는 `app/page.tsx`, 대화 이벤트와 정적 문구는 `lib/dialogue-events.ts`가 소유합니다. Vercel은 `app/api/dialogue/route.ts`, OCI는 `backend/src/routes/dialogue.ts`를 통해 대사를 중계합니다.

이전 자연어 계획 API는 배포 호환을 위해 남아 있지만 현재 게임 플레이에서 사용하지 않습니다. 신규 기능보다 완주 안정성과 폴백을 우선합니다.
