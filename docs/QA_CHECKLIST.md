# PIXEL PANIC QA 체크리스트

## 자동 검증

- [x] 같은 시드의 초기 상태가 동일하다.
- [x] 사고 확산 타이머와 후속 사고 활성화가 동작한다.
- [x] 선행 조치 후 해결 사고가 다시 확산하지 않는다.
- [x] 올바른 콤보 순서는 인정하고 역순은 거부한다.
- [x] 콤보 정의가 정확히 5개다.
- [x] 보존율과 구조·콤보 조건으로 등급을 계산한다.
- [x] Vercel 대화 프록시가 입력과 OCI 응답을 검증한다.
- [x] OCI 미설정, timeout, 429, 5xx, 잘못된 JSON은 정적 대사로 끝난다.
- [x] OCI `/api/dialogue`는 Bearer 인증과 본문 schema를 먼저 검사한다.
- [x] NPC 대화는 선택지 없는 요청만 허용하고 캐릭터별 폴백을 반환한다.
- [x] 맵 9종의 크기·색상 모드·런타임 등록을 검증한다.
- [x] TypeScript, Next.js production build, 저장소 정책 검사를 통과한다.

## 브라우저 검증

- [x] 키보드와 자연어 입력창 없이 시작할 수 있다.
- [x] 사고 → 로봇 → 행동을 클릭해 작업이 시작된다.
- [x] 로봇을 선택하면 해당 로봇과 사고에 맞는 행동 팝업이 열리고 실행 후 자동으로 닫힌다.
- [x] 클릭 구조 매뉴얼은 닫기 X 없이 표시되고 `확인`을 누르면 타이틀(Index) 화면으로 돌아간다.
- [x] 하단 HUD는 작은 작전 로그만 표시하고 단계 진행·점수·콤보 패널은 렌더링하지 않는다.
- [x] 임무 중 로봇의 중복 배치를 막는다.
- [x] 대화 폴백에서 선택 후 게임이 계속된다.
- [x] 대화 중 게임 타이머가 감속한다.
- [x] 3웨이브 브리핑이 표시된다.
- [x] 10개 사고와 5개 콤보를 거쳐 결과 화면에 도달한다.
- [x] 다시 출동이 초기 상태를 복원한다.
- [x] 일시정지와 작전 포기가 동작한다.
- [x] 1280×720에서 HUD와 패널을 읽고 클릭할 수 있다.
- [x] 1024×576, 1920×1080, 모바일 가로 화면에서 1280×720 스테이지가 비율에 맞게 축소된다.
- [x] 모바일 세로 화면에서 회전 안내가 표시된다.
- [x] 사고 카드가 실제 시설 위치에 분산되고 연결선의 타깃 점이 사고 현장을 가리키며 카드끼리 겹치지 않는다.
- [x] 사고 목록에서 항목을 선택하면 해당 현장이 좌우 메뉴 사이의 안전 영역에 자동으로 들어온다.
- [x] 대화창 화살표가 선택한 사고를 가리킨다.
- [x] 지도를 좌우로 드래그하면 배경·로봇·사고 핀이 함께 이동하고 HUD는 고정된다.
- [x] 지도 커서가 대기 중 `grab`, 드래그 중 `grabbing`으로 바뀐다.
- [x] NPC 클릭 시 캐릭터 성격에 맞는 AI 말풍선이 현장 위치에 표시되고 닫힌다.
- [x] 웨이브와 재도전에 따라 9종 맵이 순환하며 신규 4종은 고유 NPC·사고·로봇 좌표와 이동 경로를 사용한다.
- [x] 첫 타이틀 진입에서 전용 BGM을 요청하고 자동 재생이 차단되면 첫 사용자 입력에서 재생한다.
- [x] 게임 시작 시 타이틀 BGM이 임무 BGM으로 전환되고 음소거·일시정지 상태를 따른다.
- [x] 브라우저 콘솔에 치명적 오류가 없다.

## 공개 배포에서 다시 확인할 항목

- [ ] 시크릿 창에서 로그인 없이 첫 화면이 열린다.
- [ ] 실제 Vercel URL에서 한 판을 3회 연속 완주한다.
- [ ] OCI `/health`가 정상 응답한다.
- [ ] 실제 대화 응답이 5초 안에 오거나 폴백된다.
- [ ] OCI 컨테이너를 중지해도 정적 대사로 완주한다.
- [ ] 브라우저 번들과 네트워크에 API 키, OCI 토큰이 없다.
- [ ] Chrome과 Safari 또는 Edge에서 최종 점검한다.

로컬 전체 검증은 `npm run build:test && npm run qa:full`로 실행합니다. 유료 OpenAI 호출은 기본 QA에 포함하지 않습니다.
